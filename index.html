FAQ

Frequently Asked Questions

Everything you need to know about Heist Bot.

What is Heist Bot and how does it work?
Heist Bot is a free, interactive Twitch chat game that allows your viewers to team up, rob virtual banks, and earn coins. It integrates directly with your stream to boost engagement.
Is Heist Bot free to use for Twitch streamers?
Yes, the core features of Heist Bot are completely free to use. We also offer optional PRO features for advanced customization and premium support.
How do I automate Twitch minigames with Heist Bot?
Once connected to your Twitch channel, Heist Bot automatically listens for chat commands like '!raub' to start minigames, manage leaderboards, and distribute virtual coins without manual intervention.
Does Heist Bot work on every streaming platform?
Heist Bot is built for Twitch. The dashboard and OBS overlay currently run on Windows only — macOS and Linux support is on the roadmap.
